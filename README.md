# Portfolio Full Final Aufariq

Project portofolio React final yang sudah berisi:
- UI modern dan rapi
- Responsive untuk desktop, laptop, tablet, dan HP
- Animasi halus
- Hero section profesional
- Project section
- Skills section
- Journey sesuai project yang sudah dibuat
- Contact section
- Tidak menggunakan Tailwind CSS
- Tidak memakai icon bermasalah seperti Github dari lucide-react

## Cara Menjalankan

```bash
npm install
npm run dev
```

Buka:

```bash
http://localhost:5173
```

## Build Production

```bash
npm run build
```
